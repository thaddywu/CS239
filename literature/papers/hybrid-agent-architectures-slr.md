# LLM-Based Agent Systems: A Systematic Literature Review and Position on Hybrid Architectures

## Decision

**Rejected for the comprehensive-overview role.** Verified against the
[Applied Intelligence record](https://doi.org/10.1007/s10489-026-07340-9).

## Rationale

Gabauer reviews 30 peer-reviewed papers and argues for an architecture that
combines LLM reasoning, reinforcement-learning control, symbolic planning and
verification, plus cross-cutting evaluation/governance. The insistence on
process-level evaluation, auditability, and checked hybrid control is aligned
with the course.

The contribution is primarily a position supported by a small systematic
review. It does not provide a comprehensive map of agent modules and multi-agent
organization, so it is better treated as a correctness/hybrid-systems position
than as the opening architecture survey.
