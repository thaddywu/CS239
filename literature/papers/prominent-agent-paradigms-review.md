# A Review of Prominent Paradigms for LLM-Based Agents

## Decision

**Skimmed; not comprehensive enough for the requested role.** Verified against
the [COLING 2025 record](https://aclanthology.org/2025.coling-main.652/).

## Rationale

Li supplies a unified workflow vocabulary for tool use, planning (including
RAG), and feedback learning, separating environment/task, LLM-profiled roles
such as policy/evaluator/dynamics models, and reusable workflow patterns. It is
more mechanism-oriented than many broad surveys.

It intentionally omits much of memory architecture, runtime and execution
semantics, governance, and multi-agent topology. It is therefore a useful
specialized supplement, not the overview sought in this search.
