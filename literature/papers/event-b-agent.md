# Event-B Agent: Towards LLM Agent for Formal Model Synthesis and Repair

## Decision

**Candidate, not selected.** Primary source: [FSE 2026 research program](https://conf.researchr.org/details/fse-2026/fse-2026-research-papers/211/Event-B-Agent-Towards-LLM-Agent-for-Formal-Model-Synthesis-and-Repair).

Event-B Agent couples model synthesis and repair with Event-B tooling. It is an
important formal-modeling direction, but this audit did not find enough
mechanism-specific experimental evidence to displace ARTEMIS's distinguishing-
trace validation or LeanDojo's exact interactive environment. Revisit after a
full comparative evaluation is available.
