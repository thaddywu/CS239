# Semia: Auditing Agent Skills via Constraint-Guided Representation Synthesis

## Decision

**Candidate, not selected.** Current source: [arXiv 2605.00314](https://arxiv.org/abs/2605.00314); publication status unverified.

Semia lifts skill prose, interfaces, and human checkpoints into Datalog facts,
then uses constraint-guided propose/verify/evaluate synthesis and Datalog
reachability to audit 13,728 skills. Its expert-labeled subset reports 97.7%
recall and 90.6% F1. This is unusually exact-fit work on agent artifacts, but it
remains a preprint and its guarantee depends on faithful representation
synthesis. It is the clearest future challenger to the security block.
