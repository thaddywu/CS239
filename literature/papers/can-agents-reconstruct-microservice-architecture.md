# Can Agents reconstruct microservice architecture?

## Decision

**Rejected as a primary reading.** Primary source: [ESEM 2026 Emerging Results](https://conf.researchr.org/details/eseiw-2026/eseiw-2026-emerging-results-and-vision-track/11/Can-Agents-reconstruct-microservice-architecture-).

The tool-assisted, role-guided approach reconstructs services, endpoints, and
connections in 17 Java microservice systems. Its mean F1 is 0.604 for GPT-4o
and 0.254 for Llama4, with service-to-service connections especially difficult.
This is a useful negative result, but an emerging-results paper centered on
role prompts and repository exploration is not a mature recovery mechanism.
