# Automated Software Architecture Design Recovery from Source Code Using LLMs

## Decision

**Rejected as a primary reading.** Primary source: [ECSA 2025 DOI](https://doi.org/10.1007/978-3-032-02138-0_5).

The paper evaluates off-the-shelf models on class diagrams, patterns, and
architectural styles, with self-reflection as an iterative refinement step.
Results are strongest on coarse structural/style elements and weaker on class
relations and fine-grained patterns. It is relevant evidence that the modern
architecture-recovery problem is real, but prompting plus self-reflection does
not provide a reusable agentic abstraction comparable to CodePlan or IRIS.
