# Autonomous Chemical Research with Large Language Models (Coscientist)

## Metadata

Nature 2023. [Primary record](https://www.nature.com/articles/s41586-023-06792-0).

## One-line idea

Combine high-level planning, web/document search, code execution, and laboratory
APIs to design and physically run chemistry experiments.

## Technical core

Specialized modules search public sources and hardware documentation, generate
code/procedures, and control liquid-handling equipment. Observations from the
lab close the plan–execute loop, including reaction optimization.

## Evaluation and limits

Six task groups demonstrate synthesis planning, API use, and experimental
execution. Physical accomplishment is compelling, but task count is small,
human setup/safety infrastructure is substantial, and component ablations do not
isolate a broadly reusable architecture.

## Course placement and decision

**Candidate / preferred Week 10 science case.** Students should redesign its
authority, audit, interruption, and recovery model rather than infer general
agent capability from the demo.
