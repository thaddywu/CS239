# CS 239 Fall 2026 Paper List

## Primary papers

- **[AgentSquare: Automatic LLM Agent Search in Modular Design Space](https://proceedings.iclr.cc/paper_files/paper/2025/hash/0ae94013da7cd459402fd77874e09ee3-Abstract-Conference.html).** [ICLR 2025] (Tsinghua University). Planning, reasoning, tool use, and memory become modules with uniform interfaces, followed by evolutionary search over their compositions. Discuss whether this is an adequate agent architecture and whether the experiments explain the ingredients or mainly validate the search algorithm.

- **[SWE-agent: Agent-Computer Interfaces Enable Automated Software Engineering](https://proceedings.neurips.cc/paper_files/paper/2024/hash/5a7c947568c1b1328ccc5230172e1e7c-Abstract-Conference.html).** [NeurIPS 2024] (Princeton University). SWE-agent makes commands, observations, feedback, and guardrails a first-class agent-computer interface. It supports discussion of how interface design changes capability, context use, recoverability, and confinement.

- **[Multi-Agent Collaboration via Evolving Orchestration](https://proceedings.neurips.cc/paper_files/paper/2025/hash/f1320d2e2842169c6fc89dcbd80e94d0-Abstract-Conference.html).** [NeurIPS 2025] (Tsinghua University; Shanghai Jiao Tong University; Tencent Robotics X). A reinforcement-learned orchestrator dynamically selects heterogeneous agents defined by their model, reasoning pattern, and tools. Discuss learned organization versus fixed roles and what durable state, authority, concurrency, and effect semantics remain absent.

- **[Understanding the Information Propagation Effects of Communication Topologies in LLM-based Multi-Agent Systems](https://aclanthology.org/2025.emnlp-main.623/).** [EMNLP 2025] (Jilin University; Griffith University; University of New South Wales). CAPE uses counterfactual interventions to measure how useful insights and errors propagate, while EIB-Learner optimizes sparse communication topology. Discuss what this reveals about communication architecture and what it misses about trusted messages and shared state.

- **[AutoCodeSherpa: Symbolic Explanations in AI Coding Agents](https://arxiv.org/abs/2507.22414).** [ISSTA 2026, accepted in press] (National University of Singapore). Issue-derived input, infection, and output conditions become executable properties used for localization and patch rejection. Discuss when generated properties provide evidence independent of the patch generator.

- **[ImpossibleBench: Measuring LLMs' Propensity of Exploiting Test Cases](https://proceedings.iclr.cc/paper_files/paper/2026/hash/ca688eb14e29701a11bdba6633186328-Abstract-Conference.html).** [ICLR 2026] (Carnegie Mellon University; Anthropic). The framework makes requirements and tests incompatible, so every passing solution violates the specification. This is the list's evaluation-first exception for discussing oracle quality, reward hacking, test access, and why test passage is not correctness.

- **[NESA: Relational Neuro-Symbolic Static Program Analysis](https://doi.org/10.1145/3808161).** [FSE 2026] (National University of Singapore; Purdue University; Nanjing University; MegaETH). A restricted Datalog analysis combines parser facts with lazily requested neural semantic relations under fixed-point evaluation. Discuss which facts remain neural, which conclusions are symbolic, and how incorrect or missing facts propagate.

- **[Defusing Logic Bombs in Symbolic Execution with LLM-Generated Ghost Code](https://arxiv.org/abs/2603.19239).** [ISSTA 2026, accepted in press] (Peking University). Model-generated inverse relations, surrogate models, and heap partitions simplify constraints for KLEE and Z3, while every witness is replayed on the original program. The paper makes untrusted solver assistance and original-program rechecking concrete.

- **[IRIS: LLM-Assisted Static Analysis for Detecting Security Vulnerabilities](https://proceedings.iclr.cc/paper_files/paper/2025/hash/582d4e27fa24168f3af1f4582655034b-Abstract-Conference.html).** [ICLR 2025] (Cornell University; University of Pennsylvania). The model supplies source, sink, and contextual security semantics while CodeQL owns repository-scale dataflow reachability. Discuss semantic coverage, exact propagation, and the trusted boundary of model-based triage.

- **[Automating Requirements Formalization: Using LLMs and Low-Complexity Distinguishing Traces for Semantic Validation](https://conf.researchr.org/details/icse-2026/icse-2026-research-track/287/Automating-Requirements-Formalization-Using-LLMs-and-Low-Complexity-Distinguishing-T).** [ICSE 2026] (Stanford University; KBR; NASA Ames Research Center). ARTEMIS generates candidate temporal-logic meanings and small traces that distinguish them for a human reviewer. Discuss whether balanced trace selection makes semantic validation scalable and where the supported requirements language ends.

- **[RFCAudit: AI Agent for Auditing Protocol Implementations Against RFC Specifications](https://doi.org/10.1109/ASE63991.2025.00105).** [ASE 2025] (Purdue University). RFCAudit builds a hierarchical RFC index and requests clause-level code evidence on demand. Discuss the real indexing and query mechanism separately from the model-owned final conformance judgment.

- **[Automated Lemma Discovery in Agentic Program Verification](https://conf.researchr.org/details/ase-2026/ase-2026-research-track/26/Automated-Lemma-Discovery-in-Agentic-Program-Verification).** [ASE 2026, accepted in press] (National University of Singapore; Massachusetts Institute of Technology). LemmaNet proposes source-aware helper lemmas and adapts them to proof obligations, while Frama-C and Rocq check every accepted proof artifact. Discuss what neural program understanding contributes when the verifier retains exact acceptance authority.

- **[ACE: A Security Architecture for LLM-Integrated App Systems](https://www.ndss-symposium.org/ndss-paper/ace-a-security-architecture-for-llm-integrated-app-systems/).** [NDSS 2026] (Northeastern University). ACE derives an abstract plan from trusted inputs, binds it to installed apps, statically checks information flow, and executes it behind isolation and capability barriers. Discuss its trusted computing base and the cost of restricting dynamic behavior.

- **[AgentSpec: Customizable Runtime Enforcement for Safe and Reliable LLM Agents](https://conf.researchr.org/details/icse-2026/icse-2026-research-track/29/AgentSpec-Customizable-Runtime-Enforcement-for-Safe-and-Reliable-LLM-Agents).** [ICSE 2026] (Singapore Management University). A stateful policy language and external monitor intercept observable agent actions. Discuss complete mediation, temporal policy state, missing events, and the difference between enforcing a policy and establishing that the policy is correct.

- **[TraceFix: Repairing Agent Coordination Protocols with TLA+ Counterexamples](https://doi.org/10.1145/3786335.3813159).** [ACM CAIS 2026] (Rutgers University). TraceFix generates PlusCal/TLA+, model-checks coordination protocols with TLC, repairs counterexamples, and configures a runtime monitor. Its main lesson is the gap between a bounded verified model and a runtime that enforces only part of that model.

- **[Semantic Commit: Helping Users Update Intent Specifications for AI Memory at Scale](https://doi.org/10.1145/3746059.3747778).** [UIST 2025] (Harvard University; Université de Montréal; Adobe; Polytechnique Montréal). Semantic Commit treats persistent memories and rules as evolving intent specifications, then performs impact analysis, conflict detection, scoped resolution, and mixed-initiative review. Discuss how users can inspect correctness consequences that cannot be fully formalized.

## Additional candidates

- **[Agentix: An Efficient Serving Engine for LLM Agents as General Programs](https://www.usenix.org/conference/nsdi26/presentation/luo).** [NSDI 2026] (University of California, Berkeley; Google DeepMind; Shanghai Jiao Tong University). PLAS and ATLAS schedule whole dynamic agent programs using attained service, dependencies, and distributed critical paths. This is the strongest replacement if the course should emphasize agent-serving systems.

- **[Executable Code Actions Elicit Better LLM Agents](https://proceedings.mlr.press/v235/wang24h.html).** [ICML 2024] (University of Illinois Urbana-Champaign; Apple). CodeAct uses stateful executable Python as a common action language for tool use and composition. It contrasts with SWE-agent because greater expressiveness reduces orchestration friction while enlarging the validation, security, and rollback boundary.

- **[Demystifying LLM-based Software Engineering Agents](https://conf.researchr.org/details/fse-2025/fse-2025-research-papers/85/Demystifying-LLM-based-Software-Engineering-Agents).** [FSE 2025] (University of Illinois Urbana-Champaign). Agentless replaces an open-ended repair loop with fixed localization, repair sampling, and executable validation phases. It is the strongest control paper for asking which software-repair gains actually require agency.

- **[AutoCodeRover: Autonomous Program Improvement](https://doi.org/10.1145/3650212.3680384).** [ISSTA 2024] (National University of Singapore). AutoCodeRover uses AST structure and repository search to guide exploration and patch generation. It is a strong conventional repair-agent alternative, though AutoCodeSherpa provides the more distinct executable-evidence mechanism.

- **[CodaMOSA: Escaping Coverage Plateaus in Test Generation with Pre-trained Large Language Models](https://conf.researchr.org/details/icse-2023/icse-2023-technical-track/132/CodaMOSA-Escaping-Coverage-Plateaus-in-Test-Generation-with-Pre-trained-Large-Langua).** [ICSE 2023] (University of British Columbia; Microsoft Research). CodaMOSA invokes a language model only when search-based test generation stagnates, then returns generated tests to evolutionary search. Its weak-link handoff is technically clean, but it is older and less directly about coding-agent correctness.

- **[LeanDojo: Theorem Proving with Retrieval-Augmented Language Models](https://proceedings.neurips.cc/paper_files/paper/2023/hash/4441469427094f8873d0fecb0c4e1cee-Abstract-Datasets_and_Benchmarks.html).** [NeurIPS 2023, Datasets and Benchmarks] (California Institute of Technology; NVIDIA). LeanDojo exposes exact proof states, scoped premise retrieval, executable tactics, and kernel checking. It remains the clearest foundation for agent-verifier interaction but would create a second proof meeting.

- **[Defeating Prompt Injections by Design](https://www.floriantramer.com/publications/camel25/).** [IEEE SaTML 2026] (ETH Zürich; Google; Google DeepMind). CaMeL separates a privileged planner from a quarantined interpreter and propagates provenance-aware capabilities through tool execution. It remains the closest replacement for ACE; moving it to the alternate list is not a technical-depth judgment.

- **[Plan-Then-Execute: An Empirical Study of User Trust and Team Performance When Using LLM Agents As A Daily Assistant](https://doi.org/10.1145/3706598.3713218).** [CHI 2025] (Delft University of Technology; University of Queensland). A 2x2 study separates user involvement in planning from approval during execution and shows that oversight can both repair and introduce errors. It is useful supporting evidence for Semantic Commit, but its main contribution is evaluation rather than a new agent mechanism.

- **[PSearch: Search-Based Patch Generation in the Era of LLM-Based Automated Program Repair](https://conf.researchr.org/details/ase-2026/ase-2026-research-track/92/PSearch-Search-Based-Patch-Generation-in-the-Era-of-LLM-Based-Automated-Program-Repa).** [ASE 2026, accepted in press; watch list] (Nanjing University; Singapore Management University; Nanjing University of Science and Technology). The available abstract describes a structured intermediate-patch state and Monte Carlo tree search for long-horizon repair. It is not yet promoted because the full method, ablations, and limitations were unavailable for audit.

- **[Enforcing Temporal Constraints for LLM Agents](https://arxiv.org/abs/2512.23738).** [arXiv 2025, preprint] (University of Illinois Urbana-Champaign; Meta). Agent-C combines a temporal-policy language, SMT checking, and constrained generation of compliant tool calls. It is a strong unpublished mechanism but remains outside the primary list pending peer review and broader evidence.

- **[Atomix: Timely, Transactional Tool Use for Reliable Agentic Workflows](https://arxiv.org/abs/2602.14849).** [arXiv 2026, preprint] (Max Planck Institute for Software Systems; Aarhus University; EPFL). Atomix uses sealed access footprints, per-resource progress frontiers, stale-read checks, and effect-aware settlement for concurrent tool use. It directly addresses transactions around external effects but remains a preprint.

## Short framing reading

- **[Large Language Models Miss the Multi-agent Mark](https://proceedings.neurips.cc/paper_files/paper/2025/hash/cc14cadd13ca5a13ba899cb49351c139-Abstract-Position_Paper_Track.html).** [NeurIPS 2025, Position Paper Track] (University of Oxford; King's College London; University of Sussex). The paper argues that many LLM workflows use multi-agent terminology without autonomy, structured environments, explicit protocols, or meaningful emergence. A short excerpt can frame the two multi-agent primary papers without consuming a student-led slot.
